# morsechat-automata

A minimal Python/Tkinter tool that converts text into Morse code and sends it as automated, precisely-timed mouse clicks — built to key Morse into morse.halb.it.

How it works
Type your text — a live Morse preview updates as you type.
Click Calibrate position and hover your mouse over the key/button on the target site within 3 seconds.
Click Send in Morse. After a 3-second countdown (switch to your browser), the app clicks and holds at the calibrated position for the correct dot/dash duration.
Press Esc (or the Stop button) to abort at any time.

Set WPM to 50 on the site for the timing to line up correctly.
